# SaffScreen Data Deletion

**App:** SaffScreen: Masjid Display  
**Package:** `com.inucomputers.saffscreen`  
**Developer:** I.N.U. Computers, Bikaner

SaffScreen does not create an online user account and does not upload mosque settings, prayer settings, announcements, location coordinates, administrator credentials, or Taraweeh progress to an I.N.U. Computers server. This information is stored locally on the user's device.

## Delete all locally stored SaffScreen data

On Android TV:

1. Open the device's **Settings**.
2. Open **Apps** and select **SaffScreen**.
3. Select **Clear data** or **Clear storage**.
4. Confirm the deletion.

Alternatively, uninstalling SaffScreen removes its locally stored app data.

Clearing app data or uninstalling removes local settings including:

- mosque names and announcements;
- Azan and Jamat times;
- latitude and longitude;
- language, theme, font, Ramadan, and display preferences;
- Taraweeh progress;
- administrator username, password and recovery hashes, and trusted-device token;
- cached verified Hadith content.

## Reset selected information

Where an in-app reset option is available, users may reset the relevant settings without uninstalling the App. Administrator login details can also be reset using the App's recovery flow.

## Request assistance

Because SaffScreen has no cloud user account or developer-operated database containing this local information, there is normally no server-side user record to delete.

For assistance with deletion or privacy questions, email:

**inucomputersbikaner@gmail.com**

# SaffScreen का स्थानीय डेटा हटाना

SaffScreen uninstall करने से भी locally stored app data हट जाता है।
